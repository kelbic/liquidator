## ДВА ФИКСА ТРЕБУЮТ ДОРАБОТКИ (иначе регресс — не применять в форме ревью)

- **II.1:** «pop при status!=1 кроме position-healthy» — НЕПОЛНО. На СТРУКТУРНЫХ ревертах (no-route,
  Morpho-param, selector) это re-открывает слепой двойной send без sim (ровно то, ради чего дедуп
  создан -> регресс газа). Правильно: pop ТОЛЬКО на ТРАНЗИЕНТНЫХ бакетах (slippage/preconf-early) +
  трактовать `clean-on-replay` как lost-race (не поповать). Whitelist, не blacklist.
- **II.4:** «src != cache» — ПЕРЕ-отключает: `_src_out["src"]` МАРКЕТ-уровневый («cache» на весь рынок),
  а не per-borrower -> это выключило бы fast-lane на ВСЕХ money-рынках, ради которых он есть. Осмысленна
  только половина «возраст записи ≤2с», но per-borrower `last_ok_ts` сейчас НЕ прокинут в fast-lane-ветку
  (`read_positions_cached` возвращает без ts). Нужен проброс возраста ИЛИ (дешевле) роутить все
  cache-флипы в sim / ужать `_POSITION_CACHE_MAX_AGE_SEC` для fast-lane-потребителя. Не 1-строчная правка.

## СВЯЗКА (важнее суммы): II.4 -> II.1 -> II.6
Stale-flip (II.4) даёт реверт -> реверт запирает re-flip на 12с (II.1) -> если реверты кластерятся,
останавливает только дневной кап, халтя всё (II.6). Поэтому Tier-0 имеет смысл делать связкой, а не по одному.
