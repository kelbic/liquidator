# Реестр откатов — одна строка .env + рестарт

Каждый пакет несёт свой kill-switch. Строка ниже = «выключить пакет, вернуть прежнее
поведение», без отката кода. После правки .env — рестарт в тихое окно (гейт: 180с без
SPECFIRE-активности/выстрелов, HEAD == ожидаемому).

## Spec-fire / гонка предочереди (31.07)
| Пакет | Откат | Возвращает |
|---|---|---|
| Плотный каденс 0.5с×150 | `SPEC_FIRE_DENSE=0` | burst/slow 0.7/2.0с, кап 24 |
| Кэш пробы 2.5с | `SPEC_FIRE_REBUILD_SEC=5` | прежний TTL (а `=0` = пересборка каждую пробу) |
| Каскадный бакет $100 | `SPEC_FIRE_CASCADE_GAS_USD=0` | бустер мёртв, бакет всегда $20 |
| Бюджет проб $20 | `SPEC_FIRE_MAX_GAS_USD=10` | прежний бакет |
| Tip-гард проб 0.1 | `SPEC_FIRE_TIP_CAP_GWEI=1e9` | кап фактически снят (не рекомендуется) |
| Top-K ротация | `SPEC_FIRE_TOPK=1` | прежний top-1 (это и есть дефолт) |
| Сплющенная tip-лестница | `TIP_LADDER_LEGACY=1` | ступени base/mid/big + 1-в-давку |
| Гибрид каскад-детекта | `SPEC_FIRE_HYBRID=0` | бустер по одним армам (до калибровки 31.07) |
| Дробление пробы до ёмкости роута | `SPEC_FIRE_PARTIAL=0` | только полный сайз («нет свопа» на капнутых роутах — как в проигранной гонке cbDOGE 01.08) |
| Дробление fast-lane (реактив) | `REACTIVE_PARTIAL=0` | fast отказывает на капе («fast: no direct route» -> Kyber-block-loop) |
| Prearm с учётом капов роутов | `PREARM_CAP_AWARE=0` | «роут есть = прикрыт» без max_in (слепота полосы weETH $330-500k) |
| Вотчер факт-сигнала | удалить крон cascade-facts на Вене | флаг гаснет по TTL 15 мин, бустер молчит |

## Смежные контуры
| Пакет | Откат | Возвращает |
|---|---|---|
| Ассессмент в воркере | `BLOCK_ASSESS_ASYNC=0` | inline-ассессмент в recv-петле |
| Бэкофф predict-полла | `PREDICT_POLL_BACKOFF=0` | полл без бэкоффа |
| Фантом-фильтр covered | `PHANTOM_FILTER=0` | без probe-гейта |
| Мультибатч | `BATCH_LIQUIDATE=0` + контракт 0x54730E… | одиночные ликвидации |
| Katana yv-redeem v2 | `KT_CONTRACT_V2=0` + контракт 0x32156d… | v1-путь |

Принцип (kelbic, 31.07): тривиально обратимое изменение с измеримым эффектом не ждёт
«данных ради данных» — ждать стоит только там, где само ожидание производит статистику
(например, P(win) после 10 окон). Каждый новый пакет обязан добавить сюда свою строку.
