# Реестр откатов — одна строка .env + рестарт

Каждый пакет несёт свой kill-switch. Строка ниже = «выключить пакет, вернуть прежнее
поведение», без отката кода. После правки .env — рестарт в тихое окно (гейт: 180с без
SPECFIRE-активности/выстрелов, HEAD == ожидаемому).

## Spec-fire / гонка предочереди (31.07)
| Пакет | Откат | Возвращает |
|---|---|---|
| Плотный каденс 0.5с×150 | `SPEC_FIRE_DENSE=0` | burst/slow 0.7/2.0с, кап 24 |
| Кэш пробы 2.5с | `SPEC_FIRE_REBUILD_SEC=5` | прежний TTL (а `=0` = пересборка каждую пробу) |
| Каскадный бакет $100 | `SPEC_FIRE_CASCADE_GAS_USD=0` | бустер мёртв, бакет всегда $20 |
| Бюджет проб $20 | `SPEC_FIRE_MAX_GAS_USD=10` | прежний бакет |
| Tip-гард проб 0.1 | `SPEC_FIRE_TIP_CAP_GWEI=1e9` | кап фактически снят (не рекомендуется) |
| Top-K ротация | `SPEC_FIRE_TOPK=1` | прежний top-1 (это и есть дефолт) |
| Сплющенная tip-лестница | `TIP_LADDER_LEGACY=1` | ступени base/mid/big + 1-в-давку |
| Гибрид каскад-детекта | `SPEC_FIRE_HYBRID=0` | бустер по одним армам (до калибровки 31.07) |
| Дробление пробы до ёмкости роута | `SPEC_FIRE_PARTIAL=0` | только полный сайз («нет свопа» на капнутых роутах — как в проигранной гонке cbDOGE 01.08) |
| Дробление fast-lane (реактив) | `REACTIVE_PARTIAL=0` | fast отказывает на капе («fast: no direct route» -> Kyber-block-loop) |
| Prearm с учётом капов роутов | `PREARM_CAP_AWARE=0` | «роут есть = прикрыт» без max_in (слепота полосы weETH $330-500k) |
| Фолбэк цели в окне | `SPEC_FIRE_BUILD_FALLBACK=0` | прежний top-1 лок: несобираемая жир-цель монополизирует тик, меньшие жертвы без проб (гонка cbDOGE 01.08 — $4.1k ушла конкуренту) |
| Failover боевых чтений | `COMBAT_FAILOVER=0` (или пустой `COMBAT_FAILOVER_URLS`) | №2 без страховки: смерть провайдера = слепой бот до ручного вмешательства (отправки живут — SEND-3 в секвенсер) |
| Peak-owed fire-policy | `SPEC_FIRE_PEAK_OWED=0` | огонь только по текущему ret, disarm убивает окно — «оконная рулетка»: транзит, заряженный на пике, садится в отскок без наших проб (гонка cbDOGE 01.08) |
| Pending-detect (пакет A, 04.08) | `PENDING_DETECT=0` | детект только по запечатанному состоянию: минимум блок опоздания структурно (гонка №2 — победители видели транзит в формируемом блоке); лестница проб всегда на полной каденсии |
| SCHED-приоритет проб (пакет B, 04.08) | `SPEC_FIRE_SCHED=0` | прежний FCFS окон: бедное окно может съедать слоты у жирного (дыра 18:50:15→39 — 7 проб в XRP $16k, пока рвался DOGE-кит $71k) |
| Вотчер факт-сигнала | удалить крон cascade-facts на Вене | флаг гаснет по TTL 15 мин, бустер молчит |
| Live-cap роутов (04.08) | `ROUTE_LIVE_CAP=0` | статик max_in: жир сверх устаревшего капа уходит Kyber-block-loop'ом (04.08: seize 168 weETH > статик 160 при пуле до 260), осушенный пул не защищён |
| Вотчер глубины роутов | `LIVE_CAP_WATCH=0` | замер только из prearm-окон (peg-пары predict не армит — реактивный путь на протухшем капе) |
| Consume-хук live-капа (05.08) | `LIVE_CAP_CONSUME=0` | параллельные стройки одного окна видят полный кап: второй direct-сайз бьёт в осушенный первым пул (сим каскада 04.08 — B ревертит minOut за A; в батче = реверт юнита) |
| Авто-возврат flashblocks (05.08) | `FLASHBLOCK_AUTO_RETURN=0` | фолбэк односторонний до рестарта: после шторма бот живёт на newHeads (~2.1с медленнее реакции), ждёт человека и тихого окна |
| Двухскоростной кэш позиций (05.08) | `POSITION_CACHE_QUIET_INTERVAL_SEC=0` | одна скорость 30с×22 рынка (~40M CU/мес на bg-ключе — кормилец собственного 429-шторма) |
| Прореженный predict-полл (05.08) | `PREDICT_POLL_SEC=2` | прежний каденс подтверждений 2с (+~11M CU/мес bg) |
| Буст-циклы кэша на боевом ключе (05.08) | `POSITION_CACHE_COMBAT_RPC=0` | буст-циклы обратно на bg: armed-окно кормится тем же ключом, что тонет в 429-штормах (риск отравленного sizing fast-lane) |
| Страйп bg-ключей (05.08) | `BG_RPC_URL_2=` (пусто) | вся фоновая масса на одном bg-ключе (~101-114M CU/мес armed): квота-шторм ассессмента топит и триггерную ногу (preconf/predict) — класс 429-шторма 23.07 |

## Смежные контуры
| Пакет | Откат | Возвращает |
|---|---|---|
| Ассессмент в воркере | `BLOCK_ASSESS_ASYNC=0` | inline-ассессмент в recv-петле |
| Бэкофф predict-полла | `PREDICT_POLL_BACKOFF=0` | полл без бэкоффа |
| Фантом-фильтр covered | `PHANTOM_FILTER=0` | без probe-гейта |
| Мультибатч | `BATCH_LIQUIDATE=0` + контракт 0x54730E… | одиночные ликвидации |
| Katana yv-redeem v2 | `KT_CONTRACT_V2=0` + контракт 0x32156d… | v1-путь |
| Горизонт кандидат-снапшота 1.15 | `HF_API_CEILING=1.10` (+ `MEGA_HF_FILTER=1.15`, `MEGA_HF_MAX_PAGES=3`) | прежний узкий набор: стена-2 cbBTC ($29M на 10-12%) невидима, вплывает «сюрпризом» при BTC ±2% |
| Edge-слот ротации spec-fire | `SPEC_FIRE_EDGE_SLOT=0` | чистый top-K по долгу (гонка №2 06.08: ближайшая-по-dist жертва без проб) |
| Хедж preconf-сима | `HOT_SIM_CONFIRMED_RETRY=0` | skip при транспортном отказе preconf (13:30 06.08: жертву взял конкурент) |
| USDe/USDC в covered | убрать 0x54cf9be5… из INCLUDE_MARKETS + covered_markets.json (Charlotte) | рынок вне покрытия, киты $293M не жнутся |

Принцип (kelbic, 31.07): тривиально обратимое изменение с измеримым эффектом не ждёт
«данных ради данных» — ждать стоит только там, где само ожидание производит статистику
(например, P(win) после 10 окон). Каждый новый пакет обязан добавить сюда свою строку.
