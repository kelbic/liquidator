# Каскадный тир плотности — дизайн («го» kelbic 06.08; деплой ждёт ключей владельца)

## Зачем (данные)

Скан 180д (9740 ликвидаций, $111.2M repaid): стены ≥30 tx/блок берут **87%** пула и в каскад,
и в штиль; июнь = 90% полугода, топ-5 дней = 80.6%. При этом **мега-события берутся УМЕРЕННОЙ
плотностью**, не 2000-tx стенами: сингл $2.6M взят при wall=57, среднее $830k/событие при
wall=519, оператор 0x30e91ff собрал 1882 события при wall≤59. Победитель вскрытия $65.6k
(27.07): 11 EOA × 10-17 проб/блок, окно 160с, затраты $10-12.

Наш потолок сегодня: EV-плотность (e060e68) даёт **~13 проб/блок с одного EOA** — предел
nonce-очереди (пробы одного отправителя сериализуются). Паритет с одиночным снайпером есть;
в каскадный день с пулом $1M+/сутки нужен разрыв вверх: **30-60 проб/блок = 2-5 EOA залпом**.
24/7-стену НЕ строим — штилевой бонус-пул ≈$5k/мес на всё поле (подтверждено 180д).

## Механика

1. **Залповые EOA (2-5).** Каждый — свой nonce-поток: N EOA × ~13 проб/блок ≈ 26-65/блок.
   Ключи генерирует ТОЛЬКО владелец; в .env Шарлотты как `SPEC_FIRE_EOA_KEY_2..5`.
   Патрон: ~0.03 ETH на EOA (пробы $0.01-0.05; окно worst-case ~$9/EOA).

2. **Контрактный доступ — вариант A (рекомендую): контракт v4 c authorized-set.**
   `liquidate()/batchLiquidate()` пускают `owner ИЛИ isAuthorized[msg.sender]`; owner
   управляет множеством (add/remove). Один контракт = один профит-приёмник (профит всегда
   owner'у, залповые EOA — только газ). Форк-тесты как у v3 (auth, реентранси, unwrap-регресс)
   до деплоя. Вариант B (без нового контракта): клоны v3 с owner=EOA_i — работает сразу,
   но профит распылён по контрактам и sweep руками; держим как запасной.

3. **Активация — на существующих триггерах, нового детекта нет.** Залп = `fat_mode`
   (EV-плотность: жир ≥$50k в досягаемости) **И** каскад-флаг (гибрид: армы ≥4/час И
   факты ≥3/час — уже в бою с 31.07). Вне каскада тир молчит — обычная EV-плотность одним
   EOA. Раздача: round-robin целей по EOA на тик — одна цель в один блок получает пробы
   РАЗНЫХ nonce-потоков со сдвигом фазы ~50мс (заполняем разные слоты блока, свои не толкаются).

4. **Гарды (все существующие остаются):** общий probe board + WIN/LOSS-стоп любой ноги
   стопит залп по цели; отдельный бакет `CASCADE_TIER_GAS_USD` (предложение $150/день,
   внутри дневного $500; бустер $100 остаётся про реактивный путь); tip-кап проб 0.1 gwei
   на всех EOA; kill-switch видит суммарный расход всех EOA (specfire_gas_today
   агрегирует по отправителям). Откат: `SPEC_FIRE_VOLLEY=0` — тир целиком, один EOA.

5. **V2 (после первой жатвы, отдельное «го»): stateful-board по модели победителя 27.07.**
   Owner пишет армед-план в контракт до окна (borrower/размер/роут), залповые пробы = 1 байт
   калдаты; контракт исполняет план при HF<1, иначе тихий no-op. Дешевле газом и НЕ палит
   цель/расчёт (наши healthy-реверты сегодня читаются конкурентами — мотив WIN-паузы).
   Не блокирует V1 — интерфейс залпового слоя тот же.

## Экономика

Каскадный день: 3-4 жирных окна × 4 EOA × ~$9 = **$110-145 газа** против бонус-пула
каскадного дня $200k-1M+ (июнь: ~$4.4M бонусов за месяц, львиная доля за одну неделю).
Break-even = один WIN $150+ за весь каскадный день; типичный жирный приз $1.5-3k гросс.
Штиль тир не жжёт вообще (гейт «fat_mode И каскад-флаг»). Худший месяц (0 каскадов) = $0.
