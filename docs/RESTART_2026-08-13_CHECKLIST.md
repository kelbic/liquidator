# Чеклист рестарта (Г2 + спящий Ш23 + тень А1v3) — подготовлен ДО мержа р-4

> Цель: когда раунд-4 смержен, рестарт занимает минуты. Слайд 13.08 (BTC-окна: 33-35 жирных,
> $88-94M долга в досягаемости, fat-окна каждые 10-20 мин) — рестарт ТОЛЬКО в тихое окно.

## Гейт рестарта
- Тихое окно: ≥10 мин без cascade ARM и без fat-окна в логе (`journalctl -u liquidator-bot -o cat | grep "cascade ARM\|fat500k=[1-9]"`).
- Раунд-4 смержен в main, вердикт ревью положительный по каждому пакету, который едет.
- На Шарлотте: `git pull` боевого чекаута, диффа против main нет.

## ENV этого рестарта (в юнит/окружение)
| переменная | значение | почему |
|---|---|---|
| `CHAIN_INDEX_RPC_URL` | `https://base-rpc.publicnode.com` | ОБЯЗАТЕЛЕН — без него индекс не поднимется (намеренно); publicnode умеет eth_getBlockReceipts, mainnet.base.org НЕТ |
| — проверка | URL НЕ в `COMBAT_FAILOVER_URLS` и НЕ `RPC_URL` | иначе уступка ключа бою = вечный ложный «ЗАМОРОЖЕН» |
| `CHAIN_INDEX_FULL_ON_LOGS` | не задавать (дефолт '0' после правки р-4) | включение = решение kelbic (цена: 40-46мс GIL-времени на каждом заторном блоке) |
| `PROBE_TRACE` | `0` (не задавать) | Ш23 едет СПЯЩИМ; включение позже только ручкой PROBE_TRACE_CTL (после W1) |
| `TIP_REGIME` | `1` | тень А1v3 |
| `TIP_REGIME_SHARE` | `0` | тень: 0 подписей, 0 лестниц — доказано запуском р-3 |

## ЗАПРЕЩЕНО этим рестартом (отдельные решения)
`SHIP23_CANARY_FIRE=1` (никогда до G1), `PROBE_TRACE=1` в юните, крон `ship23_watch`,
`TIP_REGIME_SHARE>0`, `CHAIN_INDEX_FULL_ON_LOGS=1` без решения kelbic.

## Приёмка с НОВОГО pid (проверить pid сменился!)
1. **Г2 (а):** «CHAIN-INDEX ПРИЁМКА(60с): блоков=N>0 … дыр=0 отказов=0 … — ВЕРДИКТ: ЖИВ»
   ЛИБО законное «ЧАСТИЧНО — цепь читаю, но ПОЛНЫХ чтений в окне не было» (при FULL_ON_LOGS=0
   в штиль); ≥2 подряд «ЖИВОСТЬ(120с) … ЧИТАЮ ЦЕПЬ»; НИ ОДНОЙ строки «ЗАМОРОЖЕН» за первый час.
2. **Г2 главное число (сутки):** «#109 квитанции: … polls_saved=B index_hits=C» при B>0 И C>0,
   читать вместе со строкой «квитанции=поддержан».
3. **Тень А1v3 (30 мин):** пульс «TIPREGIME … принято_блоков=B», приёмка
   B/блоков ≥ 0.8 ПРИ regime_sigs=0 И regime_resigns=0 И смен причины regime↔stale ≤1 за 10 мин.
   Если <0.8 — флап доказан боем, SHARE>0 НЕ включается (механизм остаётся тенью).
4. **Г2 (б) на первом жирном окне:** «SPECFIRE ПОЗИЦИИ blk=…» с режимом суда («владелец известен»)
   и в закрывающей строке ДЕЛЬТА probe_no_agg=0 при probe_judged≥1.
5. Час наблюдения: CU-строки без взрыва расхода, деадмены молчат, нет новых ERROR.

## Откат (каждая ручка снимает МЕХАНИЗМ — проверено р-3)
`CHAIN_INDEX=0` (тред не поднимается) · `TIP_REGIME=0` (regime_fn=None, состояния нет) ·
Ш23 спит по построению (PROBE_TRACE=0). Рестарт с прежним коммитом — крайняя мера.
