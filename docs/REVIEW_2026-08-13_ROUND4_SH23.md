## БОЕВАЯ ПРИЁМКА
Строка, по которой родитель был бы СКЛОНЕН принять пакет боем, — вердикт (б):
«ВЕРДИКТ Ш23(б): ПОЛОЖИТЕЛЬНЫЙ (rc=0) — detect→ack p50 X мс <= 200 и ДОЛЯ ПОСАДОК Y% >= 80%;
ПРИБОР: ЖИВ …».

Число, которое тут load-bearing, — «доля посадок Y% >= 80%». Вопрос «может ли оно вырасти,
когда механизм бесполезен?» — ДА, и я это ЗАМЕРИЛ: при пуле >60 срез `[-60:]` выкидывает
провальный залп, и доля читается 100% ИМЕННО потому, что механизм усечения прячет промахи.
Второе число той же строки — «ПРИБОР: ЖИВ» — тоже держится/растёт при бесполезном механизме:
мёртвый 20ч читается ЖИВ (M1), а взведённая чужая health его фабрикует (W4). Оба числа
принимать НЕЛЬЗЯ.

Число, которое НЕ может вырасти при бесполезном механизме (предлагаю его как приёмочное):
приёмка засчитывается ТОЛЬКО если в строке напечатаны и РАВНЫ все знаменатели —
`n_burst(ЖЕТОН)=N == n_pool=N == n_asked=N == n_with_send=N` (доля посадок и p50 сняты по
ОДНОМУ множеству из N проб, усечения нет), плюс «ПРИБОР: ЖИВ (возраст последней health = Zс <
600с, pid = <именованный писатель юнита>)». Усекающий/лгущий механизм эту строку выдать не
может: R1-усечение даёт n_pool≠n_asked (у меня 90≠60), мёртвый прибор — Z>600, чужая
фабрикация — pid ≠ названного писателя. Только на такой строке «Y% >= 80%» становится
доказательством, а не артефактом среза.

Для (в) приёмка боем прежняя и проверяемая БЕЗ выстрела: «КОНВЕРТ ВЫСТРЕЛА: same_block=True
order_kept=True same_band=True foreign_between=N<=3 gap_ms(факт)=X» с квитанциями с
mainnet.base.org (закрыто, не переоткрывать).
