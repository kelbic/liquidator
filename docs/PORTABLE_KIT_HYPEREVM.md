# Portable-kit: Morpho Blue ликвидатор на HyperEVM (опыт Base-бота, 05.08)

Для сессии hyperlend («го» kelbic 05.08). Base-бот: ~6 недель боевой эволюции, этот документ —
выжимка того, что переносится, что переписывается и на каких граблях мы уже стояли.
Газ-бюджет на канарейки/тесты: ~10 HYPE «зависших» на чейне. Боевой капитал — отдельной
подписью kelbic (железное правило flow-ревью: торговый контур ≠ газ/nonce-кошелёк).

## 0. Премисс-чек — ДО любой стройки (наша доктрина: инфра-факты мерить live)

1. **Деплой Morpho Blue на HyperEVM**: адрес (на каждом чейне свой!), сверка событий по
   EventsLib.sol на закреплённом коммите (гигиена топиков, dabc604). Проверить и версию:
   Blue, не Optimizer/Vault.
2. **Multicall3** 0xcA11bde05977b3631167028862bE2a173976CA11 — обычно одинаков на всех EVM,
   но проверить кодом, не верой.
3. **Индексация**: покрывает ли blue-api.morpho.org чейн (marketTransactions по chainId).
   Схема их GraphQL ДРЕЙФУЕТ и отличается от «канонической» (сегодня: marketTransactions,
   не transactions; MarketTransactionLiquidationData; txHash; marketId, не uniqueKey; USD-полей
   нет — считать из decimals×priceUsd). Нет индексации = свой скан по логам Borrow/CreateMarket.
4. **Есть ли жатва**: история ликвидаций 90 дней (размеры, каденс). Сутки могут быть пустыми
   ($1 пыли на ВЕСЬ Base Morpho за 05.08 — это норма штиля); смотреть месяцы и стресс-дни.
   Пусто ⇒ не строить, поставить вотчер посева (паттерн SOW-WATCH: посев=ёмкость жатвы).
5. **Конкуренты**: по прошлым ликвидациям — адреса, лаг от флипа, tip-профиль (наш submit-xray
   концептуально: окно [флип..взятие], кто, чем, почём).
6. **Выходы**: КАЖДЫЙ залог прогнать квотером на боевых размерах до включения в covered.
   Урок kHYPE (ваш же): «не виден квотером вообще» = приз $333k недостижим. Урок weETH:
   стена пула на 88 при статик-капе 160.

## 2. Чейн-специфика — переписывать, не портировать

1. **Блок-источник**. Наши flashblocks (250мс) и preconf-эндпоинт — эксклюзив Base. На
   HyperEVM: малые блоки ~1с (лимит 3M — ваш замер, газ-лимит tx держать ниже) / большие
   (~1 мин, 30M). Выяснить: в какие блоки реально попадают ликвидации, какой транспорт
   даёт самое раннее видение состояния (WS? свой узел?).
2. **Оракулы**. Наш feeds/predict/prearm-стек заточен под Chainlink-агрегаторы (транзиты
   BF1, ноги, shadow-map, Binance-фронтран фидов) — НЕ портируется. На HyperEVM (Pyth/
   RedStone pull-модель) ваш существующий эдж «потребитель чужого пуша» (d07c0bf) ложится
   идеально: девиация ⇒ чей-то пуш ⇒ зонды в пуш-блок. Это правильный скелет детекта там.
3. **Выходы**. Kyber отсутствует. DEX-набор HyperEVM + их квотеры; прямые роуты первыми
   (наш урок: прямой пул доминирует 2-hop на всех размерах для cbBTC), Kyber-класс
   агрегаторов — только как fallback, если есть.
4. **Отправка/гонка**. Нет секвенсер-эндпоинта — трассу send→inclusion мерить с нуля.
   ГЛАВНОЕ: сначала разобрать, КАК выигрывают текущие победители (FCFS? прайс-аукцион?
   приватные каналы?), потом строить латентные рычаги. Наш урок стоил недель: победители
   Base СПЕКУЛИРУЮТ в предочереди, реакция структурно +1 блок, tip в FCFS не покупает место.
5. **Кандидаты без blue-api**: свой индексер по логам + пагинация, «уния» источников
   (см. грабли №1/№15).

## 3. Грабли по списку (каждая — оплаченный инцидент)

1. **HF только on-chain**. API-поле — второй сигнал в УНИИ, не единственный: ночная смена
   USD-прайсинга msETH выкинула $0.85M фронта из набора (уния вернула 29 кандидатов).
2. **Вердикт о позиции — только position() РОДНОГО mid; bs>0 ⇒ жива**. Чтение чужого рынка
   даёт честные нули и ложное «самозакрытие» (три ошибки разведки за 48ч).
3. **Отбор covered геймится**: скам-токен с оракулом-константой изобразил «$1M займа»
   (elephanToken). Фантом-проба (accessList жив? квотер выйдет?) обязательна.
4. **Безногий оракул ≠ мёртвый рынок**: JitoSOL-«фантом» оказался живым — 2 ликвидации
   ушли конкурентам. Каждый нераспознанный оракул разбирать accessList'ом.
5. **Кэш-цикл на своём ключе = свой 429-шторм** (23.07). Фоновая масса и триггер-детект —
   на РАЗНЫХ ключах (страйп); pending/спам-циклы НИКОГДА не на боевых ключах (запрет кодом).
6. **cgroup-лимиты юнита** проверять при загадочных сетевых таймаутах: реликтовый
   MemoryHigh=384M душил сокеты (128k sock_throttled) — «волна обрывов Binance» оказалась
   самодушением. Диагноз: PSI (/proc/pressure/*) и memory.events ДО гипотез про сеть/GIL.
   free -m при этом показывал 2.9G available. И: date хоста — первый шаг диагноза «тишины».
7. **Живость лога ≠ живость цикла**: mtime держал мемпул-поток при вставшем на 11ч сканере.
   Деадман — на возраст строки цикла, паттерн покрывает ВСЕ пути (err-путь без штампа дал
   ложное 💀). Приёмка сторожа: bash -x и УВИДЕТЬ извлечённую отметку.
8. **Позитивный контроль форк-сима**: не-архивный апстрим/отравленный кэш дают тихий пустой
   результат; «эффект есть» доказывается дельтой состояния, не кодом возврата (ваш же урок
   self-push).
9. **Выручка может оседать на контракте, не на кошельке** (флешлоун-схема, midnight):
   проверить путь выручки первым же боевым tx; автосвип — по «ok», не по попытке.
10. **Live-cap + partial**: seize > ёмкость роута — дробить до капа (наша проигранная
    cbDOGE-гонка: «нет свопа» на капнутом роуте отдал цель конкуренту).
11. **Гигиена процессов**: pkill -f по подстроке бьёт по себе (три инцидента) — kill по
    точному PID; тесты никогда не трогают боевые каналы (сторож на транспорте); бесхозные
    вейтеры без таймаута = висящие джобы (двое суток и 5 суток — наши экземпляры).
12. **urllib-UA** ловит 403 на публичных RPC — ходить Web3/requests-UA (SEND-3).
13. **Временный обход порога несёт срок годности** — разведочный обход пережил гипотезу и
    сыпал алертами по $2-7; алерты только там, где нужно действие человека.
14. **Каждый пакет — со строкой отката** в реестре с первого дня; тривиально обратимое с
    гардами включается сразу, ждут только там, где ожидание производит статистику.
15. **Один источник = точка слепоты** — для кандидатов, цен, вердиктов. Уния или кросс-чек.

## 4. Рекомендуемая последовательность

0. Премисс-чек (§0) — день. Пусто ⇒ вотчер посева, стоп.
1. Read-only ассессмент: индексер + батч-HF + снапшот кандидатов (warm-start с первого дня).
2. Shadow-вахта 1-2 недели: лог флипов, кто забрал, лаг победителя, размеры. Датасет гонки
   ДО первой ставки.
3. Covered-набор: выходы квотером на боевых размерах, фантом-проба, live-caps.
4. Канарейка латентности на 10 HYPE: трасса send→inclusion, попадание в малый/большой блок.
5. Первый боевой floor $10-25 (наш Midnight-урок: на первенство, не на размер), kill-switch
   и газ-капы с первого выстрела.
6. Латентные рычаги — только после разбора гонки по данным (submit-xray-класс), не до.

Вопросы/спорные места — Base-сессия на связи (STATE.md этого репо = живая история решений).
