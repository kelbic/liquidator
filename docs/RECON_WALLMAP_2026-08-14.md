2. **Окно 14 дней перекошено одним событием.** cbXRP-каскад = 81% всех событий (169/208). Один депег XRP определяет всю картину; другие режимы (спокойный рынок, депеги ETH/BTC-коллатералей) в окно не попали. Доли даны с n — но n доминируется одним рынком.
3. **covered_markets.json датирован 20.07** (снапшот, на 14.08 — 25 дней). Живой конфиг мог измениться; ssh запрещён, перемерить нельзя. cbXRP (главный поток) в снапшоте — как «new».
4. **Tip — из полей tx** (maxPriorityFee/maxFee/baseFee), не из receipt (effectiveGasPrice). Близко к реализованному, но не точная выплата.
5. **Присутствие = tx с `to==контракт`.** Про, заходящий через иной роутер/агрегатор или приватный orderflow (не публичный мемпул), не посчитан. Присутствие ≠ полная инфра команды.
