# Контур слепого ревью (kelbic 26.08: «нужен ревьюер без твоего контекста и взгляда»)

Штатный advisor сессии видит весь транскрипт — он ловит ошибки исполнения, но НАСЛЕДУЕТ
фрейминг сессии и может быть заякорен её же формулировками. Этот контур — противовес:
независимый вывод из сырых данных, сравнение ПОСЛЕ.

## Форма А: слепой вывод (в момент вердикта)

Когда сессия готова записать ЗНАЧИМЫЙ вердикт (смена диагноза, вскрытие гонки, причина
на денежном/nonce-пути, разворот направления):

1. Собрать БРИФ ТОЛЬКО ИЗ СЫРЬЯ: выдержки журнала как есть, цепные числа таблицей,
   команды для самостоятельного перемера (public RPC / read-only ssh). В брифе ЗАПРЕЩЕНЫ:
   вывод сессии, её термины-диагнозы, ссылки на STATE/Plan (это и есть «взгляд»).
2. Вопрос — нейтральный: «что является причиной X / связывающим ограничением Y?»,
   не «подтверди, что причина Z».
3. Свежий агент (general-purpose, без контекста сессии) отвечает. В промпте — явный
   запрет читать docs/STATE.md, docs/Plan.md, гит-историю сообщений.
4. Сравнение: совпал — вердикт принят двумя независимыми выводами; разошёлся — сессия
   ОБЯЗАНА разобрать расхождение до записи в STATE (не «я прав, он без контекста»).

## Форма Б: ночной адверсарий (цикл)

Ежедневный крон (~07:30Z, до утренней сводки): свежая сессия берёт из STATE за сутки
записи, помеченные `ВЕРДИКТ:`, выбирает 1-2 с наибольшим радиусом поражения и для каждой:
сначала ПЕРЕМЕРЯЕТ первичные источники (журнал/цепь/код), только потом читает обоснование
сессии; вердикт (подтверждён/опровергнут/не проверяемо + чем) кладёт в agent-inbox.
Опровержение будит ведущую сессию. Это адверсарная форма (заявление видит, вывод строит
до чтения обоснования) — слепее в кроне не получить: отбор целей требует читать STATE.

## Дисциплина квоты (каноны 13-15.08 остаются)

Слепое ревью — только на радиус «деньги/nonce/вердикт гонки/смена диагноза/разворот».
Рутинные правки судит сессия по диффу. Одна линза на вопрос; в кроне — до дешёвой модели.

## Разметка

Сессия помечает в STATE значимые выводы префиксом `ВЕРДИКТ:` — по нему ночной цикл
находит цели. Итог слепого ревью дописывается к вердикту: `[слепое ревью: совпало/
расхождение → чем кончилось]`.
