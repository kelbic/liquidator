## I. КРИТИКА СТРАТЕГИИ

### 1. Мастер-гейт «первый submit-xray» = выборка n=1 с неограниченным временем прихода
Всё стратегическое (P2-10, transmit-декодер, batch) загейчено на событие, которое рынок может не
дать неделями, и единственный экземпляр которого даст один tx-index, не win-rate (STATE:75-77,
HANDOFF:266-269). Это осознанное риск-решение владельца 07-10 («не строить вторую ставку поверх
непроверенной первой») — но неделя тишины это новые данные для пересмотра формы гейта.

**Шаг:** разложить бинарный гейт на три измеримых: (а) детекция — уже закрыта ретро (replay_winners
5/6, submit-xray валидирован 07-13); (б) inclusion-гонка — мерить canary-пробой (ниже);
(в) экономика выстрела — уже закрыта форком+QuoterV2. «Первый живой выстрел» остаётся
подтверждением, а не предусловием всех решений.

### 2. Canary-проба: гонка у секвенсера измерима ЗА ЦЕНТЫ без ликвидации ⭐ главный новый рычаг
«Выигрываем ли гонку» — вопрос про latency-до-включения после декода flashblock-события, а не про
ликвидацию. Минимальная tx (no-op к своему контракту) по реальному transmit-триггеру даёт дельту
tx-index(canary)−tx-index(transmit) — ровно ту дельту, которую ждут от submit-xray. Transmit'ы идут
постоянно (в отличие от флипов): 50–100 проб = распределение, а не n=1.

**Обязательные условия дизайна** (иначе повторяются мины P2-10): canary с **боевым tip 6 gwei**
(~21-25k газа ≈ $0.3-0.5/проба — низкий tip даст систематически пессимистичную дельту);
**мимо общего `_LOCAL_NONCE`/`_SEND_LOCK`** и с **отдельным газ-бакетом** (не в realized_today
kill-switch'а). Бюджет: 50 проб ≈ $15-25 суммарно. Это не измерение gap чужих побед (запрет STATE
не задет: свой tx-index — санкционированная метрика, STATE:22).

### 3. Сегментация reaction/atomic устарела на порядок по деньгам
gap_profile (170 ликв/30д, $1.74M reaction) мерился до 07-08 — ДО включения cbBTC/USDC
(добавлен 07-09: 482 ликв/$15.8M/30д, т.е. 9× всего замеренного сегмента). Тезис «наш сегмент
доминирует» доказан на книге, которая сейчас ~10% долларов покрытия. Доля atomic на cbBTC с его
58 ботами может быть другой — и именно она решает приоритет P2-10 vs reaction-ожидание.

**Шаг:** перегнать gap_profile полным распределением по txgap на текущем covered set (MAX_WINNERS≥300,
разбивка по рынкам). Это **measured-переоткрытие на новых данных** (прецедент — cbBTC), а не
нарушение gap-запрета: запрет защищает от малых выборок к крупным призам. В STATE явно сослаться
на запрет и причину отступления.

### 4. Модель «atomic = приватный bundle-канал» внешне НЕ подтверждается
Публичного bundle API у секвенсера Base не существует (спека rollup-boost его не описывает; ни один
источник 2026 не знает приватной подачи). Официальная политика ордеринга: priority fee эффективен
только в момент отбора / фактически в первом флэшблоке, дальше доминирует время прихода
(arXiv 2506.01462; сам README:31-32 это говорит). gap=1 при prio 0.024 gwei одинаково совместим
с «победитель читает тот же flashblocks-стрим и успевает в следующий флэшблок» — т.е. с чистой
латентной гонкой, в которой проект теперь сам играет (50-100мс до send-ack). Плюс STATE
противоречит сам себе: «atomic закрыт приватным каналом» (⛔) vs «P2-10 — единственный ПУБЛИЧНЫЙ
путь в atomic» (P2-10).

**Шаг:** переформулировать в STATE: барьер atomic-класса НЕ доказан как приватный канал; часть
atomic-объёма (~25-31% пула) потенциально достижима текущей инфрой при реакции <200мс. Проверяется
той же canary-пробой: если canary попадает в тот же блок (дельта 1-3) — atomic частично наш уже
сейчас, и потолок доступного пула растёт.

Внешняя валидация меты: на Base реверты = равновесная стратегия (20-25% priority-fee выручки
секвенсера — ревертнутые tx; боты предпочитают дубль-спам ставкам) — экономика P2-10 («реверт
$0.02 — норма») согласуется с рынком. Оговорка: статья про DEX-свапы, экстраполяция на ликвидации
правдоподобна, но не доказана.

### 5. Гейт P2-10 неинформативен для гейтуемого решения
EV standing-спама сконцентрирован на УЖЕ висящих ножах (LBTC $350k, wstETH $180k), которые
reaction-путь по собственной классификации STATE:283 НЕ берёт. Первый reaction-выстрел логически
ничего не скажет о standing-классе — а нож может флипнуть в любой день ожидания (невозвратные
$9-15k бонуса). При этом экономика плана считана для мелких призов и противоречит соседнему
«флору $50k+»; правильная рамка — **break-even hang time**: T_be = профит / $36/ч
($50k×4% → 55ч; $10k×4% → 11ч — нож, разрешающийся за часы, окупается и на $10k; LBTC-нож,
висящий 4+ суток, наоборот съел бы ~$3.5k спама против ~$9k гросс при P(win)<1 — маржа тонкая).

**Шаги (не ждать reaction-выстрела):**
- посчитать распределение hang-time позиций в полосе [1.0, 1.002) ретроспективно (hotset.log +
  реконструкция HF через историю цен оракулов — hotset.log сам HF не хранит);
- исполнить шаги 1-7 P210_CONTROL_PLAN (все zero-send: конфиг, receipt-коллектор, под-кап,
  log-only селектор) — они заодно закрывают известные предохранители;
- решение об ARM принимать формулой P(флип/мес) × бонус × P(win|standing) vs ~$36/ч × E[hang],
  где P(win|standing) как раз даст canary/микро-ARM $2/день (честно: это способ ИЗМЕРИТЬ P(win),
  а не гарантированный захват);
- в протокол: рабочий кап = $36 × ожидаемые часы покрытия (кап $2 = смоук-тест, не режим);
  авто-пауза standing при спайке basefee (спам в дорогую сеть = худший EV, и это ровно момент краша).

### 6. Горизонталь по Base — разведка сделана, расширяться почти некуда (и это хорошая новость)
Соседние протоколы проверены web-разведкой:

  latency-гонка исчезает. Не наш канал.
- **Moonwell → Chainlink OEV wrapper** (flat-fee, MIP-X43 от 15.02.2026) + свежий oracle-инцидент
  ($1.78M bad debt). Не «тонкая конкуренция», а аукцион с oracle-риском. Интерес — только мониторинг

- **Euler v2 Base** — reverse Dutch auction, гонка не латентная, маржа тонкая. **Fluid** — ~$50M, мал.
- **Seamless** — целиком мигрировал НА Morpho: его книга уже ликвидируется нашим Morpho.liquidate.
- **Morpho pre-liquidations** (permissionless призы ДО HF<1, фабрика на Base, официальный бот v4 их

  наших 40 рынках (analysis/preliq_optin_probe.py). Шаг: перепрогнать пробник свежим срезом, вердикт

**Вывод:** ставка «Morpho на Base» подтверждается внешне (USDC-депозиты Base $1.4B > mainnet,

(б) переформулировать в STATE ⛔ «покрытие расширять не на что» → «хвост Morpho-Base исчерпан
(замер 07-0X); не покрывает другие протоколы и будущие крупные рынки».
